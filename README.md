# Кэширование списка автомобилей в DRF

Небольшой API на Django REST Framework: список автомобилей кэшируется через `django.core.cache.cache`, а создание автомобиля инвалидирует кэш.

## Запуск

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости из `requirements.txt`.
3. Выполните миграции: `python manage.py migrate`.
4. Запустите сервер: `python manage.py runserver`.

API доступно по адресу `/api/cars/`:

- `GET` — отдаёт закэшированный список, если он есть; иначе читает БД и кэширует данные на 60 секунд.
- `POST` — создаёт автомобиль, удаляет `cache_key` и отвечает со статусом `201 Created`.

Пример тела `POST`:

```json
{
  "name": "Volvo XC60",
  "description": "Кроссовер",
  "price": "25000.00",
  "year": 2022
}
```

Локальный кэш настроен в `config/settings.py` как `LocMemCache` с временем жизни по умолчанию 300 секунд. Он хранится в памяти отдельного процесса и подходит для разработки и демонстрации.

## Тесты

Запустите `python manage.py test`. Набор тестов проверяет выдачу/повторное использование кэша и его сброс после создания автомобиля.
